Session Auto-Timeout

Automatically terminate sessions and patron break streams that exceed this duration limit (e.g. 5 or 10 minutes). Set to 0 to disable the auto-timeout and run sessions for the full movie duration.

When a session reaches this timeout, active playback terminates immediately, the patron is prompted to return to the auditorium, and resources are reclaimed.
